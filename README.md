# Litematica 26.3 Fabric – Compatible Build

Unofficial development build of **Litematica + MaLiLib** for Minecraft Java **26.3**.

Tested working with:

* Minecraft Java 26.3
* Fabric Loader 0.19.5
* Litematica `0.28.99-dev`
* MaLiLib `0.29.99-dev`
* MaLiLib commit `4cb96026` (RC.1)

## Downloads

Download the tested JAR files from the [Releases](../../releases) page.

## Important

This is an **unofficial development build** made for Minecraft 26.3 compatibility.

It is not an official stable release from the Litematica developers.

## Files

* `litematica-fabric-26.3-rc-1-0.28.99-dev.20260921.173733.jar`
* `malilib-fabric-26.3-rc-1-0.29.99-dev.20260921.180258.jar`

Both mods are intended for client-side use.
